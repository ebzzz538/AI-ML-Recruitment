# Student Academic Risk Prediction

## Objective
Explore academic records and use one simple Decision Tree to predict Low, Medium or High academic-support categories, then generate study recommendations.

## Dataset
The supplied Kaggle student dataset ZIP contains `dcs_student_data.csv`: 10,030 rows and 21 columns. Removing 30 duplicates leaves 10,000 unique students. Dataset source: https://www.kaggle.com/datasets/ganeshkumarofficial/student-dataset. Keep the original dataset ZIP for rerunning; it is not included in this submission package.

## Project Steps
1. Load the supplied dataset.
2. Remove duplicates, repair numeric text and mark invalid numbers as missing.
3. Explore attendance and score distributions.
4. Check attendance versus marks.
5. Define Low, Medium and High risk.
6. Split data and fill missing inputs using training medians.
7. Train and evaluate one Decision Tree.
8. Predict risk and generate rule-based advice.
9. Export the student report automatically.

The notebook has **10 code cells**. It includes four exploration plots and the required confusion matrix. Eight invalid numeric entries were marked missing, including a negative age. Age 87 was flagged but retained. Scores are provisionally /100; participation is /10, based on observed ranges.

## Risk Criteria
- **High:** Total_Score <60.
- **Medium:** 60≤Total_Score<75.
- **Low:** Total_Score≥75.

These are project-defined support bands, not official university pass/fail rules. The observed scores span roughly 50–100. The resulting groups contain 1,955 High, 3,035 Medium and 5,010 Low students.

## Model
A **Decision Tree Classifier** learns a flowchart of questions from training examples. `max_depth=5` limits its complexity. The five inputs are Attendance, Midterm_Score, Assignments_Avg, Quizzes_Avg and Participation_Score. Total_Score and other final outcomes are excluded; no names, demographic fields or categorical inputs are used.

## Results
Using 8,000 training students and 2,000 held-out test students:

| Metric | Actual result |
|---|---:|
| Accuracy | 50.15% |
| Precision (weighted) | 0.4245 |
| Recall (weighted) | 0.5015 |
| F1 (weighted) | 0.3449 |
| Attendance–total correlation | -0.0109 |

The tree predicts Low for 1,972 of the 2,000 test students and finds **only 1 of 391 actual High students**. Therefore 50.15% accuracy does **not** mean it reliably identifies students needing help. Attendance has little linear relationship with marks here. The target bands are our rule, input timing is assumed rather than verified, and the model should not determine real interventions.

# Interview Notes

### What is Machine Learning?
Learning patterns from examples to make predictions. Here we supply academic inputs and known score-based risk labels during training.

### What is Classification?
Predicting a category rather than an exact number. Our categories are Low, Medium and High.

### What is a Feature?
An input the model uses, such as attendance or midterm score. We use five numerical academic inputs.

### What is a Target?
The answer we want to predict: Risk_Level. We create it from Total_Score using the three stated bands.

### What is a Decision Tree?
A learned flowchart of questions about input values. Following the answers ends in a category prediction.

### What is Train/Test Split?
Training students teach the model; separate test students check its predictions. We use 80%/20%, with seed 42 for repeatability and stratification for similar class proportions.

### What is Data Leakage?
Giving the model information that reveals the answer or would not be available for the intended prediction. Total_Score defines risk, so it is excluded; missing values are filled using training-only medians.

### What is Accuracy?
The fraction of all predictions that are correct. It can hide poor performance on a smaller class, as it does here.

### What is Precision?
For a category, how many predictions of that category were correct? Low precision means many incorrect flags.

### What is Recall?
For a category, how many actual members did we find? Our tree found only 1 of 391 High students, so High recall is very poor.

### What is F1-score?
A score balancing precision and recall. Our overall precision, recall and F1 use weighted averages, which account for class sizes.

### What is a Confusion Matrix?
A table counting actual versus predicted categories. In this notebook rows are actual labels, columns are predictions, and diagonal entries are correct.
